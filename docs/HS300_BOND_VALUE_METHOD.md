# 沪深300股债性价比看板说明

## 看板用途

看板将沪深300价格指数走势、PE、市赚率和盈利收益率相对中国10年期国债收益率的利差放在一起观察。估值指标用于描述相对水平，不负责预测短期拐点，也不产生自动买卖信号。

## 指标定义

PE与PB采用Wind提供的沪深300指数成分股加权估值历史序列，按交易日对齐。指数点位使用沪深300价格指数（000300.SH），不与沪深300全收益指数混用。

由于历史日频ROE序列未作为独立源数据接入，历史ROE按同日PB与PE推导为隐含ROE：

\[
ROE^{*}_{t}(\%) = \frac{PB_{t}}{PE_{t}} \times 100
\]

其中 (ROE^{*}) 是估值指标隐含的ROE，不等同于财务报表披露的加权平均净资产收益率。推导依赖PE与PB具有一致指数范围、估值日和可比统计口径；不同负值处理或加权方法会带来偏差。

若Wind在相应日期返回有效ROE，看板优先使用该值，并将来源标为Wind；若无有效值，则使用PE/PB推导值。当前展示值的来源会保存在每个日期记录中。

市赚率按ROE的百分数数值计算。例如 (ROE=10\%) 时，公式中的ROE数值为10：

\[
市赚率^{*}_{t} = \frac{PE_{t}}{ROE^{*}_{t}(\%)}
\]

使用隐含ROE时，市赚率完全由PE与PB推导，不构成独立的盈利质量信号。

盈利收益率与中债版股债性价比定义如下：

\[
盈利收益率_{t}(\%) = \frac{100}{PE_{t}}
\]

\[
股债性价比_{t}(pp) = 盈利收益率_{t}(\%) - 中国10年期国债收益率_{t}(\%)
\]

利差单位为百分点（pp）。正值表示当日盈利收益率高于匹配的国债收益率，不代表股票的预期总回报。

## 数据来源与日期匹配

| 数据 | 来源与口径 |
|---|---|
| 沪深300日收盘点位 | Wind MCP，000300.SH价格指数 |
| 沪深300历史PE与PB | Wind MCP，沪深300指数成分股加权估值 |
| 最新可用ROE | 尝试从Wind MCP获取；无有效返回时使用PE/PB隐含ROE |
| 中国10年期国债收益率 | AkShare的中债收益率曲线数据，10年到期收益率 |

所有股票指标按交易日精确关联。债券收益率采用日期不晚于该A股交易日的最近有效观测；看板记录并在悬停信息中显示实际债券数据日期。不会将未来日期债券观测用于历史计算。

## 缺失与异常处理

- PE、PB、指数收盘点位和国债收益率必须是有限正数。
- PE或PB缺失或非正时，隐含ROE与市赚率留空。
- PE缺失时，盈利收益率与股债性价比留空；国债收益率缺失时，股债性价比留空。
- 不使用零填充或线性插值。历史数据刷新失败时保留上一份成功快照，并在页面显示失败原因。
- 覆盖区间取有效记录实际起止日期；源数据无法覆盖目标区间时如实显示，不补造数据。

## 看板使用方法

### 建议的阅读顺序

1. **先看沪深300指数走势**，了解当前行情所处的市场背景。指数上涨或下跌本身并不能说明估值高低。
2. **再看PE与市赚率**。PE展示价格相对指数盈利的倍数；市赚率按本看板口径由PE和ROE计算。将它们放在相同历史区间内观察，有助于判断估值相对过去处于偏高还是偏低的位置。历史ROE多数由PE/PB推导，因此市赚率与PE、PB并非相互独立的证据。
3. **最后看股债性价比**，比较沪深300盈利收益率与中国10年期国债收益率。差值上升，表示股票盈利收益率相对国债收益率的优势扩大；差值下降，表示该优势收窄。其他条件相同时，差值较高代表股票相对债券更有吸引力，差值较低则相对吸引力较弱。

### 股债性价比图的方向

为了沿用参考策略图的表达方式，股债性价比图的**纵轴倒置**：数值越大，折线位置越靠下；数值越小，位置越靠上。因此不要按常见的“曲线越高、数值越大”来读图，应以纵轴刻度和悬停数值为准。图中按界面约定用“%”符号呈现数值；公式中的差值严格来说是百分点（pp），例如7.0%减2.0%等于5.0个百分点。

### 如何用于观察

- 通过6M、1Y、3Y、5Y和全部范围切换观察窗口；拖动图表时间轴可进一步查看自选区间。短区间反映近期变化，长区间用于比较不同市场阶段。
- 观察股债利差是否相对自身历史明显扩大或收窄，并回看同期指数走势、PE及市赚率，结合判断估值背景。
- 该指标适合作为股票与债券相对估值和资产配置讨论的参考，不提供统一的高低阈值，也不能单独作为买入、卖出或仓位调整规则。参考图片中的历史时点仅用于示例，不构成未来规律。

盈利可能下滑，国债收益率也会变化；即使差值较高，也不能保证股票跑赢债券或市场即将反弹。应用时还需考虑盈利质量与趋势、ROE来源、债券利率变化、波动风险、投资期限和个人风险承受能力。
