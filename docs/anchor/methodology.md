# 双指数五年之锚：计算与回测口径

本页面是研究原型。H20903（中证A股全收益）和 H00922（中证红利全收益）是信号和理论权益代理，不能直接成交。中证红利的应用及滚动分位阈值属于本项目研究扩展，不代表原作者已验证。

## 指标

对完整参考交易日历上的每日收盘点位计算，展示区间不会截断计算历史：

- `MA_N = sum(P[t-N+1:t+1])/N`，默认 `N=1250`；上下轨分别为 `MA_N×1.15`、`MA_N×0.85`。
- `DEV=P/MA_N−1`；双指数偏离差为 `DEV(H00922)−DEV(H20903)`。
- RSI 使用 90 个涨跌差分初始化均值，再采用 Wilder 平滑：`avg=(89×avg_previous+today)/90`。上涨与下跌均为零时为 50。
- 中间缺失或本地质量表存在未解决的 `BLOCKED` 日期时，不插值、不前值填充；受影响窗口重新预热。质量记录来自当前本地数据库，和历史快照是两个独立版本。

## 信号和执行

定投在偏离率严格大于上轨阈值时暂停，等待偏离率小于或等于零时恢复；恢复信号在 T 日收盘确认，累计现金最早在下一交易日收盘投入。回测从完整历史重放状态。数据缺口会阻断后续状态，需修复数据后从头重放。

再平衡事件使用下穿 MA、下穿下轨、RSI 向上穿越 57/70；同日原因合并并只生成一个下一交易日调整。账户已在目标权重时记录无交易。月定投日为完整交易日历每月首个交易日；定期再平衡使用每年或每季度的首个交易日。

## 理论账本

四种方案为持续定投、五年之锚定投、定期再平衡和事件再平衡。前两者比较相同的每月外部投入；后两者比较相同初始本金与权益目标。防守资产是**零收益现金**，不是历史债券收益。正常月定投依据前一交易日已知状态执行；信号触发的交易不能在信号当日成交。

每日总资产等于现金加理论指数份额按当日收盘估值。佣金和滑点分别记账；总收益指数已包含再投资，因此不重复计股息。单位净值按当日开账外部现金流调整，TWR 为单位净值减一；XIRR 使用真实日期的外部流出和期末资产现金流求解。无有效现金流时返回空值。暂停周期统计包含被回测起止边界截断的区间。

## 研究

固定阈值敏感性默认测试 10%、15%、20%、25%、30%；每个 walk-forward 窗口只用训练期 TWR 选择阈值，在后续互不重叠的测试期与持续定投比较。每个测试窗口从空账户开始，但按此前历史重放信号状态；这不是连续实盘账户的样本外结果。

滚动 80% 分位数按线性插值计算，只使用当日前 756 个连续有效偏离率；恢复条件仍为 `DEV≤0`。若所选开始日早于分位数预热完成日期，则从首个可用日开始，并对同一有效区间计算基准。样本外交易数少、历史来源未知及多次参数试验均会限制结论。

## 快照及接口

指标读取现有 `data/current_manifest.json` 所指指数快照，并核对 SHA-256。回测记录保存到 SQLite 的 `anchor_backtest_runs`，研究结果保存到 `anchor_research_runs`；编号包含参数、快照、代码哈希和当前未解决质量记录哈希。保存的结果可通过 `/api/anchor/backtest/{run_id}` 或 `/api/anchor/robustness/{run_id}` 查询；不同快照或质量状态不会覆盖旧记录。

`GET /api/anchor/metrics`、`GET /api/anchor/data-quality`、`GET /api/anchor/events` 提供指标及状态；`POST /api/anchor/backtest` 和 `POST /api/anchor/robustness` 需要明确的快照编号及成本假设。`tradable_asset` 在缺少已核验真实资产数据时返回 `INSUFFICIENT_ASSET_DATA`。
