## 总体判断

FastAPI + SQLite + 原生 JS/ECharts 适合单人本地研究。采集、核验、版本化发布、质量状态及金融计算已有相当工程化基础；48 个选定离线测试通过。核心短板是**所有发布入口的门禁不一致**：`python -m scripts.update_data` 默认可跳过指数参考门禁，而 README 仍推荐该命令。此处证明的是可绕过路径，**未证明当前数据已错**。指数快照整包约 18.8 MB HTTP 响应；隔离副本 API 请求 P50 约 809 ms。轮动总览每请求重新计算，API P50 约 749 ms。UI 对核验状态的措辞与真实状态不完全一致，实际视觉效果待页面复核。
