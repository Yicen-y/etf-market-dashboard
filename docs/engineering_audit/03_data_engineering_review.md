## 数据保障现状

`scripts/fetch_data.py:18-85` 用 `FetchResult` 保存来源、上游、请求、原始字节和价格口径；`scripts/storage.py:56-126` 保存原始观察、质量问题、规范观察、发布清单及价格修订。`scripts/update_data.py:423-449` 对 ETF 尾部 7 个自然日重取；`450-480` 对新浪备用源做候选隔离与独立报价比对。指数在严格模式经 `index_verification.py:698-744` 参考门禁；`storage.py:477-529` 把价格、来源链接、待发布标记放同一 SQLite 事务，`storage.py:290-304` 再原子切换 Manifest。`scripts/snapshot.py:14-51` 校验路径及哈希。失败保留已发布快照的设计有相应离线测试。

## 代表性计算抽查

- 累计收益：`metrics.py:20-40` 为 `当日价格/基准价−1`，50/50 是两条初始各半的买入持有收益平均；`tests/test_metrics.py` 覆盖手算。ETF 未复权价格不含分红，页面 `web/app.js:75-84` 明示该口径。指数全收益展示与 ETF 价格收益分开，不能直接视为同类投资回报。
- 三棱镜：`prism_metrics.py:22-45` 显式交易日历、缺日不前填；`94-135` 对 40 日收益差和 242 日窗口给覆盖状态。未见此链路的前视读取；不等于已独立验证全部历史点位。
- 资金流：`flows.py:21-33` 份额“万份”差乘净值后除以 10000 得“亿元”；折算前份额与净值反向调整，`persistence.py:104` 调用时传空 action 避免二次调整。该结果为净申赎估算。
- 股息率：`domain.py:95-98` 以观察日前 365 天已付现金分红/价格计算；`service.py:235-251` 要求覆盖证据。回测信号 T 日收盘、下个收盘执行的意图见 `dividend/research_backtest.py:79-130` 与相关测试；本次未做交易日逐笔独立回放。

## 持续核验建议

首先堵住 CLI 门禁差异并加测试：所有正常发布入口在无编制机构参考时都应 `WITHHELD` 且旧 Manifest 哈希不变。之后把规范记录中的“结构通过/数值匹配/身份确认”分字段传播到 API 与页面，避免把不同层级混为一谈。沿用 `tests/fixtures/`、golden、隔离更新循环；每次更新后以快照 ID、行数、来源分布、缺失/异常日及哈希形成机器可读摘要。历史交付记录指出 H20180 一处推导值、H20915 特殊日历及部分供应商一分差异，属于**历史未决证据**，本轮未重新人工核验，也不把它们断言为当前错值。
