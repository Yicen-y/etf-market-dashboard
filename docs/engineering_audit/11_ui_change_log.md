## 修改顺序与验证

1. 先保存 `before_*.png` 与 `before_browser_metrics.json`。在未改文件前审阅主页面，确认证据与 P1/P2 优先级。
2. 实施 409 恢复；定向 `pytest tests/test_index_view.py tests/test_prism_ui.py tests/test_chart_theme.py` 为 14 passed。一次性 409 注入：指数请求 2 次、Manifest 请求 2 次，图表恢复；持续 409：恰好请求 2 次后显示错误。
3. 实施复合图单位表达；定向 `pytest` 加 UI 基础测试为 23 passed。浏览器对主图及全收益指数图检查单图各一条差值柱、轴名 `% / pp`、Tooltip 样本 `+20.00pp` 与 `+10.00%`，没有改变线柱数量。
4. 隔离目录发布新版本后，旧 ID 请求返回 409，新 ID 请求返回 200；最终 `activeSnapshotId` 和已绘图数据均为新 ID。版本切换时清空旧数据显示，避免中途保留旧观察卡。真实数据目录未被覆盖。
5. 完整 `pytest -q -p no:cacheprovider`：507 passed、24 skipped、2 个可选 pandas 依赖警告；现有 UI 交互脚本在隔离服务上复测，结果见 `10_ui_performance_comparison.md`。

## 风险与限制

- 页面在连续发布导致两次固定快照请求都返回 409 时停止自动尝试并显示错误；用户可刷新重试。这是有意的有限重试，避免循环。
- 只验证了 Chrome Headless 1440×900、375×812 及当前隔离数据。其他浏览器、真实在线更新、断网和触屏手势未全量覆盖。
- A07 的大文件耦合尚未整体拆分；只对与本轮故障直接相关的版本读取路径做局部梳理。
- 除 ETF/指数复合图之外的颜色、布局和控件统一建议暂不实施，避免改变既有研究操作习惯。
