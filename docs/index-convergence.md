# 指数核验收敛（2026-11-15）

`scripts/config.py` 的 `INDEXES` 仍是唯一注册表。运行 `python -m scripts.index_convergence` 从已有中证、国证和华泰柏瑞证据重建 `index_converged_status`，主键为指数代码和交易日期。该表是可重算的判定投影；原始采集、参考批次、原始响应、任务及 `index_prices.source` 不改写。完整逐日明细在 SQLite，汇总和策略假设测算在 `data/verification/convergence-summary.json`。

## 判定维度

- `numeric_status`：优先看编制机构接口的实际点位；若接口无有效点位，才列示供应商补充值。两位小数容差为 0.005 点，国证官方四位小数容差为 0.00005 点。
- `identity_status`：按原有身份资料和响应校验。480080/480081 仍为 `CURRENCY_UNCONFIRMED`，不能以供应商英文名称推断币种。
- `source_status`：区分编制机构 HTTP 原始响应、AkShare 解析响应、华泰柏瑞业务响应及无可用响应。两个包装器指向同一上游时不算独立发布机构。
- `original_source`：来自正式行情的原始采集来源，`PROVENANCE_UNKNOWN` 保持原样；后补参考来源另列。
- `calendar_status`：`CALENDAR_EXCEPTION` 为有证据的非交易日，`CALENDAR_REVIEW` 为待判定占位行；H20915 不使用 A 股日历。
- `quality_status`：单日当前核验结论；供应商不同值不会被静默忽略。`current_publication_policy` 要求仅对新增或修改的候选点位执行当日门禁，历史补证缺口本身不使当天所有数据失去发布资格。

## 81 条差异及新增发现

华泰柏瑞全历史响应的原始数值字段最多显示两位小数，四条原先缺原始响应的指数分别有 27、6、24、24 个日期比本地高 0.01 点，合计 81 条。原始响应没有第三位小数，无法证明具体舍入规则；一分差异仍超出 0.005 点容差，分类为 `UNEXPLAINED_VENDOR_PRECISION_OR_REVISION`。另有 H00300 一条和 H20915 十二条同方向一分差异。共 94 条，均是供应商较高；其中 29 条已有编制机构 HTTP 响应支持本地值。不能把这些差异提高容差后宣布一致。

使用既有 `calculate_prism_metrics` 的 40 日收益差公式，以供应商点位假设替换同日正式值，仅作敏感性测算。四条相关指数的单日收益率差最大约 0.0521 个基点、40 日收益率差最大约 0.0506 个基点；相关策略 40 日收益差最大变化约 0.000565 个百分点，本次样本无优势方向翻转。逐日影响、年份分布和策略明细均在汇总 JSON 中。结果不表示未来信号不会翻转。

- H00300 于 2026-11-10：本地 6112.80 与中证官方原始响应 6112.80 一致；供应商为 6112.81。列为供应商差异，正式值不改。
- H20180 于 2013-06-28：中证官方原始响应为零，华泰柏瑞对应历史窗口无点位，本地推导修复值仍无法独立确认。
- H20915：中证缺 65 个本地日期，华泰柏瑞也缺同样的 65 个；供应商另缺 2018-06-18、2018-12-25。2018-06-18 与 2026-11-07 的异常日期结论维持；38 条中证零成交量占位行继续逐项复核，不把 A 股日历套用于该指数。
- 480080/480081：官方四位小数点位全覆盖，华泰柏瑞提供英文全收益名称，但官方计价货币字段仍缺。

## 2026-11-17 用户授权的渠道点位放行规则

新增行情候选值与同代码、同日期的官方点位绝对差值 **严格小于 0.05 点** 时，可以按用户授权规则放行。等于或大于 0.05 点仍受阻。此规则独立于上文所述的官方公布精度，不改变逐日精度对账的原始结果，也不代表官方确认了渠道点位完全相同。

放行仍须通过指数身份与收益口径、适用日期、官方原始响应哈希、其他渠道原始响应哈希校验；国证指数原有身份路线核准继续有效，核准表分别保存官方和 AkShare 实际点位及放行依据。显式标为价格指数或未复权点位的响应不能参与放行。`index_converged_status.detail_json` 保留原始点差和 `accepted_by_user_point_rule`，一分差异的原始统计仍保留。正式 `index_prices`、Manifest 和快照不会因为调整规则或重建投影而自动改写。
