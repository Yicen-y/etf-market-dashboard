# ETF 红利研究模块整合实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有本地 ETF 看板中增量交付中证红利股息率、红利对数回归、A/H共同交易日动量，并整合五年之锚与研究回测。

**Architecture:** 复用 SQLite `index_prices`、`scripts/anchor` 纯计算/回测、既有 FastAPI router 与导航/ECharts；新数据采用可追溯的统一事实及红利研究表。官方股息率和国债数据若不可核验则明确缺失，不作代理估算。

**Tech Stack:** Python、FastAPI、SQLite、HTML/JavaScript、ECharts、pytest。

## Global Constraints

- 保留既有 ETF 轮动、资金流向、股息监测和五年之锚功能。
- 数据仅使用可验证真实来源；来源未知标记待核验；不填充缺失值。
- A/H比较使用人民币全收益序列及共同有效交易日。
- 历史信号不得使用未来数据；信号日收盘不得假定同收盘成交。
- 指标研究与可交易回测分开；不得将指数代理收益标记为 ETF 实盘收益。
