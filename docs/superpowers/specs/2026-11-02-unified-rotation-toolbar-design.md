# 轮动看板统一横向数据控制条设计

## 目标

将所有轮动看板顶部的数据控制区域统一为三棱镜页面现有的横向布局。桌面端依次展示基准日期、实际基准交易日、刷新全部数据和策略说明；窄屏下自动恢复纵向排列。

## 范围

- 覆盖普通ETF轮动看板和全部三棱镜轮动看板。
- 复用现有 `control-panel ui-toolbar` HTML结构及按钮事件。
- 只调整布局和响应式样式，不修改基准日解析、数据刷新、策略说明、图表或指标计算。
- 不修改红利看板和沪深300 ETF资金流向模块。

## 实现方式

1. 将当前仅由 `.prism-active .control-panel` 启用的桌面端网格布局提升为轮动主页面的默认 `.control-panel` 布局。
2. 保留现有控件顺序和语义标签，确保键盘访问与事件绑定不变。
3. 在 `850px` 以下切换为纵向布局，日期输入框和两个按钮占满可用宽度，提示文字允许换行。
4. 保留 `.prism-active` 仅用于三棱镜图表区域的行为，不再用它决定顶部工具栏样式。

## 验收

- “300红利与300成长轮动”桌面端控制区与三棱镜页面一致，为单行横向工具栏。
- 三棱镜及其他轮动页面布局不退化。
- 基准日期、实际基准交易日、刷新全部数据、策略说明均正常工作。
- 窄屏无横向溢出、遮挡或按钮截断。
- JavaScript语法检查及既有测试通过。
