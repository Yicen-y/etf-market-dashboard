# A股ETF看板 Soft Bento UI 设计说明

**日期：** 2026-11-14  
**方案：** A（统一视觉层，逐页改造）

## 目标

在不修改现有 FastAPI、SQLite、金融指标、数据源和页面路由的前提下，将现有页面统一为适合桌面与移动端的专业金融 Soft Bento 看板。

## 视觉原则

- 保留浅色主题，页面背景使用淡蓝灰，内容使用白色卡片。
- 主色为蓝色；中国市场语义保持红涨绿跌。
- 信息密度偏高，但使用清晰的标题、辅助文字、KPI 与图表层级。
- 卡片圆角统一为 16px，控件圆角 10px，胶囊状态使用 999px。
- 阴影只用于层级，不使用强发光、厚重玻璃拟态或大面积渐变。
- 动效保持轻微，并遵循 `prefers-reduced-motion`。

## 页面框架

### 桌面端

- 左侧 240px 固定导航。
- 主内容最大宽度 1680px。
- 页面头部由标题信息区和紧凑工具栏组成。
- KPI 使用响应式 Bento 网格。
- 图表、表格和详情分别放在独立卡片中。

### 移动端

- 900px 以下切换为顶部折叠菜单。
- 480px 以下 KPI 单列，工具栏字段单列。
- 图表高度压缩并保留横向缩放能力。
- 所有点击目标不小于 44px。

## 导航

保留现有路由与业务含义，重新梳理层级：

- 轮动总览
- 数据中心
- 轮动看板
- 红利看板
  - ETF股息率
  - 股票股息率
- 五年之锚
- 红利研究
- 股债性价比
- 沪深300 ETF资金流向
- 设置

只有当前页面或策略显示激活状态，并保留 `aria-current="page"`。

## 页面优先级

1. 全局主题、导航和共享组件
2. ETF轮动与三棱镜
3. 股息率监测
4. 沪深300 ETF资金流向
5. 五年之锚、红利研究和股债性价比

## 数据与行为约束

- 不修改金融计算和数据获取逻辑。
- 不更改现有 API 路径。
- 加载、成功、部分完整、陈旧、错误状态均须明确显示。
- 图表继续使用 ECharts，保留 Tooltip、DataZoom、CSV 和联动功能。
- 缺失值显示为“—”，不得展示为 0。

## 验收

- 375px、768px、1024px、1440px 无横向页面滚动。
- 导航激活状态唯一。
- 键盘可操作导航、按钮与弹窗。
- 红涨绿跌语义一致。
- 原有页面测试和金融计算测试不受影响。
